# Xeta File Manager Privacy Policy

Effective date: October 11, 2026

This policy explains how Xeta File Manager handles information when you use the app.

## Browse by folder or file type

If you grant Android's Manage all files access, the app can browse files and folders in shared storage, including internal storage and connected storage that Android makes available. You can browse by folder or by file type. The app uses file names, paths, file types, sizes, and timestamps on your device to show file lists and properties. Photos and videos may be read to show previews or thumbnails. The app only performs file operations that you initiate, such as opening, copying, moving, renaming, or deleting items.

## No data or metrics collected

Xeta File Manager collects no personal data, files, file names, paths, search terms, browsing activity, or usage metrics. File browsing and management happen on your device. The app does not transmit app data to Xeta or to third parties, and it does not require an account.

## Open-source code

All source code for Xeta File Manager is open source. Find our source code here: https://github.com/xetawallet/Xeta-File-Manager-App

## Information stored on your device

The app stores a small number of preferences in its private app storage, such as onboarding completion, your light or dark theme choice, and whether you enabled OTG writing. Browsing searches and file lists are not kept as an activity history. The app does not keep copies of files it displays or manages.

These preferences remain on the device until you clear the app's storage or uninstall the app. Android may handle device backups according to your device and account settings.

## File access and actions

You can grant or revoke Manage all files access in Android settings. Without that access, browsing shared storage is unavailable. Connected OTG storage starts read-only; you can separately enable writing in the app's Settings. File actions change files on the selected storage. Delete permanently removes the selected item using Android file operations and may not be reversible. Copy, move, and rename stop when the destination name already exists; they do not replace the existing item.

When you choose to open a file, Android may pass temporary read access to a compatible app on your device so that app can display it. The privacy practices of that app are controlled by its provider.

## Sharing and collection

Xeta File Manager does not transmit app data to the developer or other third parties. The app does not sell or share personal information. Android and Google Play may process information under their own services and policies when you install or use an app distributed through Google Play.

The donation screen displays public cryptocurrency addresses and creates QR codes on your device. The app does not access a wallet, initiate transactions, or send donation information. If you copy an address into a wallet or open the source-code link, that external app or website applies its own privacy practices.

## Children's privacy

Xeta File Manager is a general-purpose utility and does not knowingly collect personal information from children.

## Security and your choices

Files remain under Android's storage permissions and the access controls of your device. Keep your device protected with its screen lock and review storage permissions in Android settings. You can turn off storage access there, disable OTG writing in app Settings, clear the app's storage, or uninstall the app.

## Changes to this policy

This policy may be updated when the app's behavior changes. The effective date above will be revised when an update is published. Check the current policy from the developer's Google Play listing.

## Contact

For privacy questions, contact the developer using the contact address listed on the Xeta File Manager Google Play store page.
